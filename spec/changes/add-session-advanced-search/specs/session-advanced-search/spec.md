# session-advanced-search — 会话高级搜索

## ADDED Requirements

### Requirement: 搜索框内高级搜索入口注入

插件 client 半 SHALL 在官方侧栏会话搜索框（`@deepseek-ai/dsh-client-ui-sidebar` 渲染的搜索输入框）内部、清除（X）按钮的左侧注入一个仅显示图标的按钮（无文字），hover/焦点时 SHALL 给出「高级搜索」提示文案；注入 MUST NOT 改变官方搜索框自身的标题搜索行为。官方搜索框 DOM 签名与预期缝不符（缝漂移）时，插件 SHALL 打 warn 级日志并跳过注入，MUST NOT 抛错破坏侧栏其余功能。

#### Scenario: 注入成功

- **WHEN** 用户在侧栏点击搜索、官方搜索框出现
- **THEN** 搜索框内 X 按钮左侧出现一个仅图标的「高级搜索」按钮，hover 显示「高级搜索」提示
- **AND** 官方标题搜索功能行为不变

#### Scenario: 缝失配降级

- **WHEN** 官方搜索框 DOM 结构与插件预期的锚点签名不匹配（如官方升级改版）
- **THEN** 插件记录 warn 级日志且不注入按钮，侧栏与搜索框功能不受影响、无未捕获异常

### Requirement: 高级搜索弹窗

点击「高级搜索」按钮 SHALL 弹出高级搜索弹窗，弹窗内包含：会话内容描述的自由文本输入区（必填）、可选的开始日期与结束日期范围字段、「开始搜索」提交按钮与关闭途径（关闭按钮/Esc）。描述为空时提交按钮 SHALL 不可用。弹窗关闭后再次点击按钮 SHALL 能重新打开且状态重置。弹窗文案 SHALL 为中文。

#### Scenario: 打开弹窗

- **WHEN** 用户点击搜索框内的「高级搜索」图标按钮
- **THEN** 弹出高级搜索弹窗，含描述输入区、可选起止日期字段、提交按钮与关闭途径

#### Scenario: 空描述不可提交

- **WHEN** 描述输入为空或仅空白字符
- **THEN** 提交按钮不可用

#### Scenario: 关闭后重开状态重置

- **WHEN** 用户关闭弹窗后再次点击「高级搜索」按钮
- **THEN** 弹窗重新打开，输入与结果状态重置为初始态

### Requirement: 分析任务发起与进度展示

用户提交搜索后，client 半 SHALL 经同源 HTTP API 向 host 半发起分析任务（POST），弹窗 SHALL 进入进度态并轮询任务状态，展示阶段性进度文案（至少区分：收集会话、预筛候选、agent 分析中）。分析为独立后台任务：MUST NOT 把搜索请求或分析过程写入、依赖或展示于当前会话的对话上下文。同一 client 同时最多一个在途任务；在途时再次提交 SHALL 取消前一个任务并开始新任务。用户关闭弹窗 SHALL 允许（任务可继续在后台完成或按实现取消，MUST NOT 阻塞或报错打断用户）。

#### Scenario: 提交后进入进度态

- **WHEN** 用户填写描述（可含时间范围）并提交
- **THEN** 弹窗显示阶段性进度文案，且当前会话的对话记录中不出现本次搜索的任何痕迹

#### Scenario: 重复提交取消前任务

- **WHEN** 上一个分析任务仍在进行时用户修改描述并再次提交
- **THEN** 前一个任务被取消（其结果不再被采用），新任务开始执行

### Requirement: 会话收集与机械预筛（只读、全工作区）

host 半 SHALL 只读收集本 profile 全部会话产物（覆盖所有工作区，不限发起搜索时所在工作区），并按以下规则机械预筛出候选集：提供了时间范围时 SHALL 仅保留活动时间落在范围内的会话；SHALL 按描述关键词对标题等机械可判字段做匹配计分。候选集 MUST 有数量上限（配置项约束，超限按评分与最近活跃截断）。整个分析过程 MUST NOT 修改任何会话产物。

#### Scenario: 时间范围过滤

- **WHEN** 用户提交时提供了开始/结束日期
- **THEN** 只有活动时间落在该区间内的会话进入候选集，区间外的会话（即使标题高度匹配）不进入 agent 分析

#### Scenario: 分析只读

- **WHEN** 一次分析任务执行前后对比
- **THEN** 所有会话产物的内容与修改时间均无变化

#### Scenario: 候选上限

- **WHEN** 预筛后候选会话数超过配置上限
- **THEN** 按机械评分与最近活跃度截断至上限，仅截断后的候选进入 LLM 分析

### Requirement: LLM 语义分析与结果排序

host 半 SHALL 调用 profile 既有配置的 LLM，对候选集中每个会话的摘要信息（至少含标题、活动时间、工作区路径、首条用户消息节选）与用户描述做语义匹配，返回按匹配度排序的 Top-N（默认 5，配置项约束）候选，每个候选 MUST 附匹配理由与置信度。LLM 服务不可用、调用失败或超时（上限约束）时，SHALL 回退为机械评分排序并返回候选，结果界面 SHALL 标注「LLM 分析不可用，已按机械匹配排序」。无任何匹配时 SHALL 展示空态文案。

#### Scenario: 命中目标会话

- **WHEN** 用户描述「上周修登录功能的会话」且候选集中存在该会话（stub LLM 按既有匹配返回其排名第一）
- **THEN** 结果列表第一位为该会话，且附匹配理由与置信度

#### Scenario: LLM 失败回退

- **WHEN** LLM 调用失败或超时
- **THEN** 接口仍返回机械评分排序的候选，结果界面标注降级说明，功能不报错中断

#### Scenario: 无匹配空态

- **WHEN** 预筛与 LLM 分析后无任何候选
- **THEN** 弹窗展示中文空态文案（如「未找到匹配的会话」），不展示空列表错误

### Requirement: 结果展示与一键跳转

结果列表中每个候选 SHALL 展示：会话标题、所属工作区、活动时间、匹配理由与置信度标注。用户点击任一候选 SHALL 关闭弹窗并把主视图切换到该会话（与在侧栏点击该会话同效），跳转 MUST NOT 要求用户先手动切换到该会话所属工作区；跨工作区会话 SHALL 可直接跳转。

#### Scenario: 点击候选跳转

- **WHEN** 用户点击结果列表中的某个候选
- **THEN** 弹窗关闭，主视图切换为该会话的对话内容

#### Scenario: 跨工作区跳转

- **WHEN** 选中的会话不属于当前激活工作区
- **THEN** 跳转仍然生效，主视图直接呈现该会话内容
