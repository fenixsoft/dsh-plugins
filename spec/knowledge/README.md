# spec/knowledge

项目知识真相源：蒸馏归档 SPEC 中仍然成立的当前业务规则，按能力域组织。入口见 [index.md](index.md)，架构裁定见 [adr/index.md](adr/index.md)。

## 域命名映射表

| 域名 | 业务含义 |
| --- | --- |
| provider-import | 把外部载体（cc-switch）托管的 provider 清单导入 dsh web 的能力聚类 |
| session-search | 在全部工作区的历史会话中按自然语言描述定位目标会话的能力聚类 |
| maintree-stray-wip | 主树散件 WIP 盘点信号的收编口径聚类 |
| plugin-rollout | 把本仓 dsh 插件装入真实 dsh web 实例并在真机上完成验收的能力聚类 |
| sidebar-navigation | dsh web 侧栏内容组织与导航形态定制的能力聚类（功能/工作区分区直达等） |
